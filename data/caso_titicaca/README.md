# El caso de campo

Resultados del estudio de intervisibilidad de la cuenca del Titicaca
(doi:10.5281/zenodo.22176260) citados por el articulo como instancias
documentadas de fallo silencioso. Se copian aqui los tres ficheros que
respaldan las cifras citadas, para que la auditoria del manuscrito pueda
cotejarlas sin depender de un repositorio externo:

- nulo_rigido.json             el contraste corregido (z = +2.63 a 5 km)
- nulo_rigido_sin_mascara.json el contraejemplo del agua (z = -0.08)
- nulo_rigido_n300.json        el contraejemplo del recorte (z = +4.49)
